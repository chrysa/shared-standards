# Auto-maintained documentation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reference documentation (structure, routes, data model, components) is regenerated from the code by a deterministic script, and a pre-commit gate fails when it has drifted or when a new folder has no `README.md`.

**Architecture:** A new generator `gen_docs.py` plus an extractor module `gen_docs_extractors.py`, both authored in `templates/` (single source of truth) and synced to `scripts/` of every repo, exactly like `gen_context_files.py`. Extractors read source text statically (`ast`, regex); nothing of the target repo is imported or executed. A `docs-drift` pre-commit hook runs `gen_docs.py --check`; `release.yml` already replays the whole pre-commit suite, so no release change is needed.

**Tech Stack:** Python 3.11+ stdlib (`ast`, `re`, `subprocess`, `argparse`), optional `pyyaml==6.0.2` for `project-profile.yml`, pytest, pre-commit, bash.

**Spec:** `docs/superpowers/specs/2026-10-10-auto-maintained-docs-design.md`

## Global Constraints

- Extraction is **static only**: never `import` or execute the target repo's code.
- **Determinism is a contract**: stable ordering, sorted lists, repo-relative `/` paths, `\n` newlines, **no timestamps, dates, absolute paths, hostnames or random values** in any generated byte.
- The generator writes only inside `docs/reference/` or between `<!-- chrysa:docs:<name>:start -->` / `<!-- chrysa:docs:<name>:end -->` markers; everything outside markers stays byte-identical.
- **Blocking** (exit 1): generated docs stale/missing-when-required; a **newly created** directory that directly contains a source file and has no `README.md`. **Warning only** (exit 0): covered source changed while no `*.md` / `docs/` file changed.
- "Newly created" = no tracked file existed in that directory (or below it) at the base commit. Base = `HEAD` for the pre-commit hook (staged changes), the merge-base with the default branch (`--base REF`) when replayed at release.
- A repo opts in with a `docs:` list in `project-profile.yml`; when the key is absent, stack detection chooses the extractors and a **missing** generated file is **not** a failure (a repo is never blocked by a drift it had no chance to fix).
- Initial extractor set: `structure`, `routes` (FastAPI), `data-model` (Django), `components` (React). New extractors are additive.
- Everything written to disk is in English. Never `--no-verify`, never disable a hook.
- `AGENTS.md`, `CLAUDE.md` core block, `standards/rules/*.md`, `CORE.chrysa.md` and the Copilot view are **generated**: edit `standards/STANDARDS.chrysa.md`, then run `make gen-agent-views`. Never hand-edit the generated files.
- Authoring convention: write each generator file in `templates/`, then `cp` it to `scripts/` (the dogfood copy). A parity test (Task 5) keeps them identical.
- **Commit hygiene (user's global post-commit hook):** a `graphify-archify` post-commit hook may fold `graphify-out/*` into every commit. After every commit run `git show --stat HEAD`; if `graphify-out/` paths appear, remove them without bypassing the hook, using plumbing: build a temp index (`GIT_INDEX_FILE=<tmp>`), `git read-tree HEAD`, `git update-index --cacheinfo 100644,<blob-of-merge-base-version>,<path>` for each such path, `git write-tree`, `git commit-tree <tree> -p HEAD -m "<msg>"`, `git reset --soft <new-commit>`.
- Test command everywhere: `python3 -m pytest <path> -q` from the repo root (the repo's `pyproject.toml` already passes `-p no:query_optimizer -p no:django`).

## Review Focus

Failure modes the spec implies but no happy-path test would catch, most likely first. Each has a test in the owning task.

1. **Self-listing instability**: the `structure` doc lists `docs/reference/structure.md` itself, so the first run and the second run differ and the gate fires forever. Generated files must be excluded from the extractor input. (Task 3)
2. **Unreadable or CRLF files**: a non-UTF-8 file, a CRLF checkout, or a file that vanishes must not crash or change output. (Tasks 2, 8, 9, 10)
3. **Python syntax errors in a scanned file** (routes, data-model): listed as `not parsed`, never a crash, never a silent skip. (Tasks 8, 9)
4. **No git / git with no commit yet**: the walk fallback must work, and the README check on the very first commit must not crash. (Task 4)
5. **Markers**: a block for an unselected/unknown name, or a start marker without an end marker, must be left untouched and must not raise. (Task 3)

## Context

The canon requires documentation to stay in lockstep with the code, but only as a human
duty checked in review: nothing fails when a reference page goes stale. Routes, the data
model, the component inventory and the repository structure are facts derivable from the
source, so keeping them by hand is both error-prone and avoidable.

## Decision

Reference documentation is generated by `scripts/gen_docs.py` from static source
extraction and drift-gated by a `docs-drift` pre-commit hook; prose stays human-written.

## Fatal hypothesis

Static extraction of routes, models, components and structure is byte-stable across
machines and operating systems, so the drift gate never fires on a change that did not alter
the code surface.

## Kill-test

On each pilot repo (`shared-standards`, `devtool`, `django-migration-analyzer`, `logos`),
count commits in the first two weeks after activation where `docs-drift` failed although the
code surface did not change (a false positive: regenerating on a clean checkout of another
machine changes the output). If more than 1 of the 4 repos shows one, the decision is
`Killed`. Mechanised by the determinism tests in `tests/scripts/test_gen_docs.py`; the
two-week fleet tally is manual, recorded in this ADR's status history.

## Validation gate

Before any fleet distribution: the generator runs clean and idempotently on
`shared-standards` and on the three pilots, and a second run produces zero diff.

## Options considered

| Option | Why not |
| ------ | ------- |
| Build on `doc-gen` | Every repo would depend on a tool with its own environment constraints (graphviz, Django plugins); the reference facts do not need a site generator. |
| Per-language monolithic generator | Large to maintain per stack; extractors are additive here instead. |
| LLM bot rewriting prose | Non-deterministic, cannot be a blocking gate; explicitly out of scope. |

## Consequences

- **Accepted costs:** extraction is incomplete by nature (dynamic routers, generated models);
  each generated block states what it could not resolve.
- **Gains:** reference docs cannot silently rot; the lockstep rule becomes mechanical for the
  deterministic part.
- **Debt:** heuristic code-without-doc detection stays a warning until proven precise.
- **Blast radius if Killed:** remove the `docs-drift` hook, `scripts/gen_docs*.py`, the
  `deploy_docs_generator` step in `apply-repo-standard.sh`, and the canon bullet.

```python
"""Static extractors for the reference-documentation generator (ADR D-0018).

Each extractor reads source *text* of the target repo (``ast``, line scanning) and returns
deterministic markdown. Nothing here imports or executes the target repo's code.

An :class:`Extractor` carries four things: its ``name`` (also the generated file name), a
``detect`` predicate (does this repo have anything of that kind), a ``render`` function
(markdown body, no banner) and a ``covers`` predicate (is a changed path one this extractor
documents; used only by the non-blocking warning).

Determinism is a contract: sorted output, repo-relative ``/`` paths, ``\\n`` newlines, no
timestamps or absolute paths. Anything unreadable degrades to ``(not available)`` / a
``not parsed`` line, never to a crash and never to differing output.
"""

from __future__ import annotations

from collections.abc import Callable
from dataclasses import dataclass
from pathlib import Path

NA = "(not available)"
_STRUCTURE_DEPTH = 2


@dataclass(frozen=True)
class Extractor:
    """One kind of reference documentation derivable from source."""

    name: str
    detect: Callable[[Path, list[str]], bool]
    render: Callable[[Path, list[str]], str]
    covers: Callable[[str], bool]


def read_source(root: Path, rel: str) -> str | None:
    """UTF-8 text of ``rel`` with ``\\n`` newlines, or None when it cannot be read."""
    try:
        text = (root / rel).read_text(encoding="utf-8")
    except (OSError, UnicodeDecodeError):
        return None
    return text.replace("\r\n", "\n")


# ── structure ─────────────────────────────────────────────────────────────────────────────


def _directories(files: list[str]) -> list[str]:
    """Sorted directories (down to ``_STRUCTURE_DEPTH`` levels) that hold at least a file."""
    dirs: set[str] = set()
    for rel in files:
        parts = rel.split("/")[:-1]
        for level in range(1, min(len(parts), _STRUCTURE_DEPTH) + 1):
            dirs.add("/".join(parts[:level]))
    return sorted(dirs)


def _count_under(files: list[str], directory: str) -> int:
    prefix = directory + "/"
    return sum(1 for rel in files if rel.startswith(prefix))


def detect_structure(root: Path, files: list[str]) -> bool:  # noqa: ARG001
    """Any repo with at least one file has a structure."""
    return bool(files)


def covers_structure(path: str) -> bool:  # noqa: ARG001
    """Structure documents everything and therefore never drives the code-without-doc warning."""
    return False


def render_structure(root: Path, files: list[str]) -> str:  # noqa: ARG001
    """Directory table: file count and whether the directory carries a ``README.md``."""
    present = set(files)
    rows = ["| Directory | Files | README |", "| --- | ---: | :---: |"]
    for directory in _directories(files):
        has_readme = "yes" if f"{directory}/README.md" in present else "no"
        rows.append(f"| `{directory}/` | {_count_under(files, directory)} | {has_readme} |")
    if len(rows) == 2:
        return NA + "\n"
    return "\n".join(rows) + "\n"


# ── registry ──────────────────────────────────────────────────────────────────────────────

STRUCTURE = Extractor(
    name="structure",
    detect=detect_structure,
    render=render_structure,
    covers=covers_structure,
)

EXTRACTORS: tuple[Extractor, ...] = (STRUCTURE,)
BY_NAME: dict[str, Extractor] = {extractor.name: extractor for extractor in EXTRACTORS}
```

Create `templates/gen_docs.py`:

```python
"""Generate a repo's reference documentation from its own source (ADR D-0018).

Reference facts (structure, routes, data model, component inventory) are derived by the static
extractors in ``gen_docs_extractors`` and written either to ``docs/reference/<name>.md`` (a
fully generated file) or into ``<!-- chrysa:docs:<name>:start -->`` ... ``:end -->`` blocks
that already exist inside a tracked markdown file. Nothing outside those two places is ever
touched. The target repo's code is never imported or executed.

Run ``python -m scripts.gen_docs`` to (re)write the docs, or ``python -m scripts.gen_docs
--check`` for the drift gate (the ``docs-drift`` pre-commit hook). A repo opts in with a
``docs:`` list in ``project-profile.yml``; without it, stack detection picks the extractors and
a *missing* generated file is not a failure.

Determinism is a contract (same as ``gen_context_files``): no timestamps, absolute paths or
random values in any generated byte.
"""

from __future__ import annotations

import argparse
import re
import sys
from pathlib import Path
from typing import NamedTuple

from scripts import gen_context_files
from scripts import gen_docs_extractors as extractors
from scripts.gen_docs_extractors import Extractor

try:  # pyyaml is optional: without it the profile is ignored and detection applies.
    import yaml
except ImportError:  # pragma: no cover - exercised only on hosts without pyyaml
    yaml = None

_ROOT = Path(__file__).resolve().parents[1]

REFERENCE_DIR = "docs/reference"
PROFILE = "project-profile.yml"
BANNER = (
    "<!-- GENERATED by scripts/gen_docs.py (ADR D-0018) — do not edit. "
    "Regenerate with `make gen-docs`. -->"
)
_MARKED = "chrysa:docs:"
_BLOCK = re.compile(
    r"(?P<head><!-- chrysa:docs:(?P<name>[a-z-]+):start -->\n)"
    r"(?P<body>.*?)"
    r"(?P<tail><!-- chrysa:docs:(?P=name):end -->)",
    re.DOTALL,
)


class Expected(NamedTuple):
    """What a generated path must contain, and whether its absence counts as drift."""

    content: str
    required: bool


# ── selection ────────────────────────────────────────────────────────────────────────────


def project_files(root: Path) -> list[str]:
    """Repo files minus our own output, so generation is a fixed point (never self-listing)."""
    prefix = REFERENCE_DIR + "/"
    return [rel for rel in gen_context_files.repo_files(root) if not rel.startswith(prefix)]


def profile_extractors(root: Path) -> list[str] | None:
    """Extractor names listed under ``docs:`` in ``project-profile.yml``, or None if not opted in."""
    text = extractors.read_source(root, PROFILE)
    if yaml is None or text is None:
        return None
    try:
        data = yaml.safe_load(text)
    except yaml.YAMLError:
        return None
    names = data.get("docs") if isinstance(data, dict) else None
    if not isinstance(names, list):
        return None
    return sorted({str(name) for name in names})


def unknown_extractors(root: Path) -> list[str]:
    """Names in the profile that match no extractor."""
    listed = profile_extractors(root) or []
    return [name for name in listed if name not in extractors.BY_NAME]


def select(root: Path, files: list[str]) -> list[tuple[Extractor, bool]]:
    """Active extractors, each flagged True when the profile lists it explicitly."""
    listed = profile_extractors(root)
    if listed is not None:
        return [(extractors.BY_NAME[name], True) for name in listed if name in extractors.BY_NAME]
    return [(item, False) for item in extractors.EXTRACTORS if item.detect(root, files)]


# ── rendering ────────────────────────────────────────────────────────────────────────────


def _title(name: str) -> str:
    return name.replace("-", " ").capitalize()


def render_file(extractor: Extractor, root: Path, files: list[str]) -> str:
    """A fully generated ``docs/reference/<name>.md``."""
    return f"{BANNER}\n\n# {_title(extractor.name)}\n\n{extractor.render(root, files)}"


def splice_blocks(text: str, bodies: dict[str, str]) -> str:
    """Replace the body of every complete marker block whose name has a generated body."""
    out: list[str] = []
    last = 0
    for match in _BLOCK.finditer(text):
        body = bodies.get(match.group("name"))
        if body is None:
            continue
        out.append(text[last : match.start("body")])
        out.append(body)
        last = match.end("body")
    out.append(text[last:])
    return "".join(out)


def generate(root: Path) -> dict[str, Expected]:
    """Every path this generator owns, mapped to its expected content."""
    files = project_files(root)
    chosen = select(root, files)
    bodies = {item.name: item.render(root, files) for item, _ in chosen}
    expected = {
        f"{REFERENCE_DIR}/{item.name}.md": Expected(render_file(item, root, files), explicit)
        for item, explicit in chosen
    }
    for rel in files:
        text = extractors.read_source(root, rel) if rel.endswith(".md") else None
        if text is None or _MARKED not in text:
            continue
        spliced = splice_blocks(text, bodies)
        if spliced != text:
            expected[rel] = Expected(spliced, True)
    return expected


def write_all(root: Path) -> None:
    """Write every owned path (bytes, so newlines never depend on the host)."""
    for rel, item in generate(root).items():
        path = root / rel
        path.parent.mkdir(parents=True, exist_ok=True)
        path.write_bytes(item.content.encode("utf-8"))


# ── drift gate ───────────────────────────────────────────────────────────────────────────


def drift(root: Path) -> list[str]:
    """Drift lines (empty when every owned file is current)."""
    lines = [f"unknown extractor in {PROFILE}: {name}" for name in unknown_extractors(root)]
    for rel, item in sorted(generate(root).items()):
        actual = extractors.read_source(root, rel)
        if actual is None:
            if item.required:
                lines.append(f"missing: {rel}")
        elif actual != item.content:
            lines.append(f"stale: {rel}")
    return lines


def check(root: Path, base: str | None = None) -> int:  # noqa: ARG001  (base used from Task 4)
    """Run the gate: print problems to stderr and return the process exit code."""
    problems = drift(root)
    if not problems:
        return 0
    sys.stderr.write("reference docs check failed:\n")
    for line in problems:
        sys.stderr.write(f"  - {line}\n")
    sys.stderr.write(
        "run `make gen-docs` (or `python -m scripts.gen_docs`) and commit the result.\n"
    )
    return 1


def main(argv: list[str] | None = None, root: Path = _ROOT) -> int:
    """CLI entry point: regenerate, or ``--check`` for the drift gate."""
    parser = argparse.ArgumentParser(description="Generate reference docs from source.")
    parser.add_argument("--check", action="store_true", help="fail on drift instead of writing")
    parser.add_argument("--base", default=None, help="base ref for the new-folder check")
    args = parser.parse_args(argv)
    if not args.check:
        write_all(root)
        return 0
    return check(root, args.base)


if __name__ == "__main__":
    raise SystemExit(main())
```

def _git_lines(root: Path, *args: str) -> list[str] | None:
    """Non-empty stdout lines of ``git -C root <args>``, or None when git fails/is absent."""
    try:
        result = subprocess.run(
            ["git", "-C", str(root), *args], capture_output=True, text=True, check=True
        )
    except (OSError, subprocess.CalledProcessError):
        return None
    return [line for line in result.stdout.splitlines() if line]


def _diff_names(root: Path, base: str | None, kind: str) -> list[str] | None:
    """Paths of the change set filtered by ``kind`` (``A`` added, ``AM`` added/modified)."""
    scope = ["--cached"] if base is None else [base, "HEAD"]
    return _git_lines(root, "diff", "--name-only", f"--diff-filter={kind}", *scope)


def is_source(path: str) -> bool:
    """A source file outside vendored, hidden and build directories."""
    parent_parts = path.split("/")[:-1]
    if any(part in SKIP_PARTS or part.startswith(".") for part in parent_parts):
        return False
    return path.endswith(SOURCE_SUFFIXES)


def _ancestors(path: str) -> Iterator[str]:
    """Every parent directory of ``path`` (``a/b/c.py`` yields ``a/b`` then ``a``)."""
    for parent in PurePosixPath(path).parents:
        if str(parent) != ".":
            yield str(parent)


def _dirs_at(root: Path, ref: str) -> set[str]:
    """Every directory that held a tracked file at ``ref`` (empty when ref does not exist)."""
    tracked = _git_lines(root, "ls-tree", "-r", "--name-only", ref) or []
    return {parent for rel in tracked for parent in _ancestors(rel)}


def new_dirs_missing_readme(root: Path, base: str | None = None) -> list[str]:
    """Newly created directories that directly hold a source file and carry no README.md."""
    added = _diff_names(root, base, "A")
    if added is None:
        return []
    existing = _dirs_at(root, base or "HEAD")
    missing: set[str] = set()
    for rel in added:
        directory = str(PurePosixPath(rel).parent)
        if directory == "." or directory in existing or not is_source(rel):
            continue
        if not (root / directory / "README.md").is_file():
            missing.add(directory)
    return sorted(missing)


def changed_files(root: Path, base: str | None = None) -> list[str]:
    """Added or modified paths in the change set (empty when git is unavailable)."""
    return _diff_names(root, base, "AM") or []


def docs_warning(changed: list[str], active: list[Extractor]) -> str | None:
    """Non-blocking hint: covered source changed while no documentation did."""
    covered = sorted(path for path in changed if any(item.covers(path) for item in active))
    touched_docs = any(path.endswith(".md") or path.startswith("docs/") for path in changed)
    if not covered or touched_docs:
        return None
    return (
        f"warning: {len(covered)} source file(s) covered by the reference docs changed but no "
        f"documentation was touched (first: {covered[0]})"
    )

# ── shared AST helpers ────────────────────────────────────────────────────────────────────


def _python_files(files: list[str]) -> list[str]:
    return [rel for rel in files if rel.endswith(".py")]


def _parse(text: str) -> ast.AST | None:
    """Parse Python source, or None when it is not valid (syntax error, NUL byte)."""
    try:
        return ast.parse(text)
    except (SyntaxError, ValueError):
        return None


def _callee_name(call: ast.Call) -> str:
    """``f(...)`` -> ``f``; ``a.b(...)`` -> ``b``; anything else -> empty string."""
    func = call.func
    if isinstance(func, ast.Name):
        return func.id
    if isinstance(func, ast.Attribute):
        return func.attr
    return ""


def _keyword_literal(call: ast.Call, key: str) -> str | None:
    """The string-literal value of keyword ``key``, or None."""
    for keyword in call.keywords:
        value = keyword.value
        if keyword.arg == key and isinstance(value, ast.Constant) and isinstance(value.value, str):
            return value.value
    return None


def _keyword_source(call: ast.Call, key: str) -> str:
    """The source text of keyword ``key``, or an empty string."""
    for keyword in call.keywords:
        if keyword.arg == key:
            return ast.unparse(keyword.value)
    return ""


def _unparsed_lines(unparsed: list[str]) -> list[str]:
    return [f"- not parsed: `{rel}`" for rel in sorted(unparsed)]


# ── routes (FastAPI) ──────────────────────────────────────────────────────────────────────

_HTTP_METHODS = frozenset({"get", "post", "put", "patch", "delete", "head", "options"})
_ROUTE_HINTS = ("route", "api", "endpoint", "view", "main", "app")
_ROUTES_LIMITS = (
    "_Limits: router prefixes passed to `include_router(...)` are not resolved; "
    "non-literal paths are omitted._"
)


class Route(NamedTuple):
    """One HTTP route; field order is the sort order of the generated table."""

    path: str
    method: str
    handler: str
    response: str
    file: str


def _router_prefixes(tree: ast.AST) -> dict[str, str]:
    """``name = APIRouter(prefix="/x")`` assignments: variable name -> literal prefix."""
    prefixes: dict[str, str] = {}
    for node in ast.walk(tree):
        if isinstance(node, ast.Assign) and isinstance(node.value, ast.Call):
            if _callee_name(node.value) != "APIRouter":
                continue
            for target in node.targets:
                if isinstance(target, ast.Name):
                    prefixes[target.id] = _keyword_literal(node.value, "prefix") or ""
    return prefixes


def _literal_path(decorator: ast.Call) -> str | None:
    if not decorator.args:
        return None
    first = decorator.args[0]
    if isinstance(first, ast.Constant) and isinstance(first.value, str):
        return first.value
    return None


def _route_of(
    decorator: ast.expr, handler: str, rel: str, prefixes: dict[str, str]
) -> Route | None:
    """The route declared by one decorator, or None when it is not a literal HTTP route."""
    if not isinstance(decorator, ast.Call) or not isinstance(decorator.func, ast.Attribute):
        return None
    owner = decorator.func.value
    method = decorator.func.attr
    path = _literal_path(decorator)
    if method not in _HTTP_METHODS or not isinstance(owner, ast.Name) or path is None:
        return None
    response = _keyword_source(decorator, "response_model")
    return Route(prefixes.get(owner.id, "") + path, method.upper(), handler, response, rel)


def _routes_in(tree: ast.AST, rel: str) -> list[Route]:
    prefixes = _router_prefixes(tree)
    found: list[Route] = []
    for node in ast.walk(tree):
        if not isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef)):
            continue
        for decorator in node.decorator_list:
            route = _route_of(decorator, node.name, rel, prefixes)
            if route is not None:
                found.append(route)
    return found


def _mentions_fastapi(text: str | None) -> bool:
    return text is not None and "fastapi" in text.lower()


def detect_routes(root: Path, files: list[str]) -> bool:
    return any(_mentions_fastapi(read_source(root, rel)) for rel in _python_files(files))


def covers_routes(path: str) -> bool:
    lowered = path.lower()
    return lowered.endswith(".py") and any(hint in lowered for hint in _ROUTE_HINTS)


def render_routes(root: Path, files: list[str]) -> str:
    """Route table (method, path, handler, response model, file) plus the documented limits."""
    routes: list[Route] = []
    unparsed: list[str] = []
    for rel in _python_files(files):
        text = read_source(root, rel)
        if not _mentions_fastapi(text):
            continue
        tree = _parse(text or "")
        if tree is None:
            unparsed.append(rel)
            continue
        routes.extend(_routes_in(tree, rel))
    lines: list[str] = []
    if routes:
        lines += ["| Method | Path | Handler | Response model | File |", "| --- | --- | --- | --- | --- |"]
        for route in sorted(routes):
            lines.append(
                f"| {route.method} | `{route.path}` | `{route.handler}` | "
                f"{('`' + route.response + '`') if route.response else ''} | `{route.file}` |"
            )
    else:
        lines.append(NA)
    lines += ["", _ROUTES_LIMITS, *_unparsed_lines(unparsed)]
    return "\n".join(lines) + "\n"


ROUTES = Extractor(
    name="routes", detect=detect_routes, render=render_routes, covers=covers_routes

# ── data model (Django) ───────────────────────────────────────────────────────────────────

_RELATION_FIELDS = frozenset({"ForeignKey", "OneToOneField", "ManyToManyField"})


class FieldRow(NamedTuple):
    """One declared model field."""

    name: str
    kind: str
    relation: str


def _is_model_file(rel: str) -> bool:
    parts = rel.split("/")
    return rel.endswith(".py") and (parts[-1] == "models.py" or "models" in parts[:-1])


def _is_model_class(node: ast.ClassDef) -> bool:
    """A class deriving from ``Model`` or ``<module>.Model``."""
    for base in node.bases:
        if isinstance(base, ast.Name) and base.id == "Model":
            return True
        if isinstance(base, ast.Attribute) and base.attr == "Model":
            return True
    return False


def _field_of(statement: ast.stmt) -> FieldRow | None:
    """The field declared by ``name = models.XField(...)``, or None."""
    if not isinstance(statement, ast.Assign) or not isinstance(statement.value, ast.Call):
        return None
    if len(statement.targets) != 1 or not isinstance(statement.targets[0], ast.Name):
        return None
    call = statement.value
    kind = _callee_name(call)
    if not kind.endswith("Field") and kind not in _RELATION_FIELDS:
        return None
    relation = ast.unparse(call.args[0]) if kind in _RELATION_FIELDS and call.args else ""
    return FieldRow(statement.targets[0].id, kind, relation)


def _model_section(node: ast.ClassDef, rel: str) -> list[str]:
    lines = [f"### `{node.name}` — `{rel}`", ""]
    fields = [row for row in map(_field_of, node.body) if row is not None]
    if not fields:
        return lines + ["_no declared fields_", ""]
    lines += ["| Field | Type | Relation |", "| --- | --- | --- |"]
    for row in fields:
        relation = f"`{row.relation}`" if row.relation else ""
        lines.append(f"| `{row.name}` | `{row.kind}` | {relation} |")
    return lines + [""]


def detect_data_model(root: Path, files: list[str]) -> bool:
    for rel in files:
        if _is_model_file(rel):
            text = read_source(root, rel)
            if text is not None and "django" in text.lower():
                return True
    return False


def covers_data_model(path: str) -> bool:
    return _is_model_file(path)


def render_data_model(root: Path, files: list[str]) -> str:
    """One section per Django model class, in file then source order."""
    sections: list[str] = []
    unparsed: list[str] = []
    for rel in sorted(rel for rel in files if _is_model_file(rel)):
        text = read_source(root, rel)
        if text is None or "django" not in text.lower():
            continue
        tree = _parse(text)
        if tree is None:
            unparsed.append(rel)
            continue
        for node in ast.walk(tree):
            if isinstance(node, ast.ClassDef) and _is_model_class(node):
                sections += _model_section(node, rel)
    lines = sections if sections else [NA, ""]
    lines += _unparsed_lines(unparsed)
    return "\n".join(lines).rstrip("\n") + "\n"


DATA_MODEL = Extractor(
    name="data-model",
    detect=detect_data_model,
    render=render_data_model,
    covers=covers_data_model,
)

_EXPORT_FUNCTION = re.compile(r"^export\s+(?:default\s+)?function\s+([A-Z]\w*)\s*\(", re.MULTILINE)
_EXPORT_CONST = re.compile(r"^export\s+const\s+([A-Z]\w*)\s*[:=]", re.MULTILINE)
_PROPS_NEAR = re.compile(r"([A-Z]\w*Props)\b")
_PROPS_WINDOW = 200
_NOT_COMPONENT_MARKERS = (".test.", ".spec.", ".stories.", "__tests__")


def _is_component_file(rel: str) -> bool:
    parts = rel.split("/")
    if not rel.endswith(".tsx") or any(part in {"node_modules", "dist", "build"} for part in parts):
        return False
    return not any(marker in rel for marker in _NOT_COMPONENT_MARKERS)


def _props_type(text: str, start: int) -> str:
    """The first ``*Props`` type name in the window after a component declaration."""
    match = _PROPS_NEAR.search(text, start, start + _PROPS_WINDOW)
    return match.group(1) if match else ""


def _components_in(text: str, rel: str) -> list[tuple[str, str, str]]:
    found: list[tuple[str, str, str]] = []
    for pattern in (_EXPORT_FUNCTION, _EXPORT_CONST):
        for match in pattern.finditer(text):
            found.append((match.group(1), _props_type(text, match.end()), rel))
    return found


def detect_components(root: Path, files: list[str]) -> bool:
    return any(_is_component_file(rel) for rel in files)


def covers_components(path: str) -> bool:
    return _is_component_file(path)


def render_components(root: Path, files: list[str]) -> str:
    """Component inventory: name, props type (when named ``*Props``), file."""
    rows: list[tuple[str, str, str]] = []
    for rel in files:
        text = read_source(root, rel) if _is_component_file(rel) else None
        if text is not None:
            rows += _components_in(text, rel)
    if not rows:
        return NA + "\n"
    lines = ["| Component | Props | File |", "| --- | --- | --- |"]
    for name, props, rel in sorted(set(rows), key=lambda row: (row[2], row[0])):
        lines.append(f"| `{name}` | {('`' + props + '`') if props else ''} | `{rel}` |")
    return "\n".join(lines) + "\n"


COMPONENTS = Extractor(
    name="components",
    detect=detect_components,
    render=render_components,
    covers=covers_components,
)
