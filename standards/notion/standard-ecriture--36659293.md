# ✍️ Standard Écriture

<table_of_contents/>
> **✍️ Standard Écriture** · production littéraire ou musicale · rythme et créneau bloqué avant tout · IA = brainstorming/relecture jamais écriture.
## 🎯 Identité du type
Projet d'écriture ou de composition : roman, nouvelle, court métrage, chanson, BD, manifeste. Cycle de production long et irrégulier par nature. Spécificité clé : **rythme d'écriture déclaré et créneau bloqué** plutôt que délais durs. Notion = espace canonique d'écriture pour ce type. Différencié des autres types par l'absence de code et la primauté du contenu créatif.

## ✅ Gates applicables
- **Gate Cadrage → Spec** : univers/tone défini en 3 mots · références listées
- **Gate Spec → Dev** : plan/outline complet · personnages principaux fichés · **rythme d'écriture déclaré + créneau bloqué dans le calendrier**
- **Gate Dev → Review** : brouillon complet (100% des chapitres/sections en état lisible)
- **Gate Review → Test** : relecture personnelle achevée · inconsistances traitées
- **Gate Test → Pilote** : ≥1 lecteur externe confirmé · retours intégrés ou justifiés
- **Gate Pilote → Prod** : publication effective (auto-édition, blog, plateforme) ou abandon assumé (Sunset)
## 📑 Contenu attendu
> Légende : `*` obligatoire · `+` recommandé · `📄` section inline (H2 dans la page) · `📁` sous-page dédiée · `📄/📁` au choix selon volume
- `*📄` **🎯 Pitch (logline)** — en 1 phrase : protagoniste + objectif + obstacle (fiction) · sujet + angle (manifeste/essai)
- `*📄` **📖 Format** — type (Roman / Nouvelle / Court métrage / Chanson / BD / Manifeste), longueur cible, public cible
- `*📄` **🌈 Univers / Tone** — genre principal, ambiance en 3 mots, références
- `*📄` **✍️ Rythme d'écriture** — créneau (ex : 1h/sem, 30 min/jour), outil utilisé, rôle de l'IA (brainstorming + relecture, JAMAIS écriture à la place)
- `*📄` **📜 État actuel** — version courante, chapitres/sections prêts, bloquant actuel, prochaine action en 1 ligne
- `*📁` **Plan / Outline** — sous-page (souvent volumineux, évolutif)
- `*📁` **Études (faisabilité principalement, marché si édition)** — via [template subpage Études v2](https://www.notion.so/36659293e35e81f69470ee692d4f843b)
- `*📁` **Suivi** — journal + mots écrits + sessions hebdo · via [template subpage Suivi](https://www.notion.so/36359293e35e8106ace1e8691e082f66)
- `+📁` **Worldbuilding** — sous-page si univers riche
- `+📁` **Chapitres / Scènes** — sous-pages (une par chapitre potentiellement, ou page parente avec sections)
- `+📁` **Personnages** — sous-page (fiches)
- `+📁` **Notes & inspirations** — sous-page (références, idées vrac)
- `+📄` **🎮 Gamification** — quête liée si applicable (ex : "Écriture 500 mots" = N XP/jour)
- `+📁` **🚨 ADRs créatifs** — choix majeurs (POV, structure narrative, ton, structure des actes)
## 🚨 Critères Risk Window
- 🔴 **Critique** : projet en pause \>6 mois sans créneau d'écriture
- 🟠 **At-risk** : projet sans rythme régulier · créneau hebdo non tenu
- 🟢 **Safe** : rythme tenu · mots/semaine ou sessions hebdo régulières
- ⚫ **Lost** : projet en pause \>12 mois → déclarer Sunset (libération)
## 🛑 Non-négociables
- **IA = brainstorming + relecture, JAMAIS écriture à la place**
- **Rythme réaliste déclaré** dès Spec (ex : 500 mots / semaine, 1 session de 1h hebdo)
- **Créneau bloqué dans le calendrier** — pas "quand j'aurai le temps"
- **Pas d'illustrations générées par IA** dans les rendus publiés (sauf si explicitement le sujet)
- **Versionnement clair des manuscrits** — ne pas écraser, dater chaque version majeure
- **Distinction perso/édition explicite** dès Cadrage (impact Études marché + Pertinence)
