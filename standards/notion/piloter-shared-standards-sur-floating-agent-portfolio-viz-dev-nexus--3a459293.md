# Piloter shared-standards sur floating-agent, portfolio-viz et DEV Nexus

## Objectif
Faire des trois projets actifs l’anneau canari de toute évolution `shared-standards`.
## Critères d’acceptation
- [ ] Origine et version du template visibles dans chaque fichier synchronisé ou généré.
- [ ] Aucun fork manuel non documenté des workflows, Makefiles, conventions ou structures documentaires.
- [ ] Les différences spécifiques au projet passent par paramètres ou extensions prévues.
- [ ] CI verte sur les trois projets avant propagation à la flotte.
- [ ] Un rollback de synchronisation est documenté.
- [ ] Le nombre de fichiers divergents avant/après est mesuré.
